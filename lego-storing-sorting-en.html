Storing and sorting LEGO bricks: tips for order

Anyone with more than a few sets knows the problem: the bricks end up in one box, and finding the right part takes longer than the build. A little order keeps the hobby manageable.

The tips on this page are general and have not been tested by us. What counts are always the details on the box and on the manufacturer's website.

Deutsche Fassung

Sorting by set or by parts

There are two basic approaches. If you keep the bricks of a set together, you can rebuild the set later as the instructions show it. If you sort by parts, you find what you need faster when building freely.

You can combine both: sets you want to rebuild stay together, everything else goes into the parts sorting.

Ordering by colour and type

A simple order: first roughly by colour, then by type, for example plates, bricks, tiles and special parts. Sorting too finely costs time. Start coarsely and refine only where you search often.

Choosing containers

Flat boxes with compartments or drawers give an overview, transparent containers save opening them. Label the containers. Large parts belong in different containers than very small ones, so nothing gets mixed up.

Finished models

Finished models belong on a stable shelf, protected from dust and vibration. If a model is no longer needed it can be taken apart. A photo of the finished model helps if you want to rebuild it later.

Keeping the instructions

Keep instructions flat in a folder, sorted by set number. The manufacturer also provides instructions digitally; the set number helps you find them.

Safety

Store the bricks so that small children and pets cannot reach small parts.

Checklist

  • ☐ Decided: by set, by parts or both
  • ☐ Containers found or bought, and labelled
  • ☐ Instructions filed flat and by set number
  • ☐ Finished models displayed protected from dust
  • ☐ Small parts out of reach of children and pets

Frequently asked questions

Should I sort by colour or by set?

Both have advantages and drawbacks. If you want to rebuild sets later, keep the bricks together by set. If you build freely, sorting by colour and type usually gets you there faster.

How do I store a set I have not built yet?

Preferably in the original box, dry and out of direct sunlight. Leave the bags unopened until the build begins.

What do I do with single leftover bricks?

Put them in a container for loose parts. First check in the instructions whether they belong to the set.
